**固定外壳，三栏工作区**：

```text
┌──────────────────────────────────────────────────────────────┐
│ TopBar：品牌 · 模式 · 撤销/重做 · 项目操作 · 保存状态            │
├────────────┬───────────────────────────────┬─────────────────┤
│ LeftRail   │ ViewportStage                 │ RightDock       │
│ 工具/笔刷  │  three.js 画布 + HUD 覆盖层    │ 标签页：        │
│ 调色板     │                               │ AI / 图纸 / 结构 │
│ 取色器     │                               │ 操作 / 噪声 /    │
│            │                               │ 历史 / 显示      │
├────────────┴───────────────────────────────┴─────────────────┤
│ StatusBar：方块数 · 构件 · 组合 · 最后一条消息                  │
└──────────────────────────────────────────────────────────────┘
```

- **r07（UI 重构）**：移除 r05 的「9 个悬浮方块」体系（`ui/floating/` 整目录删除）——
  面板收进右栏 Dock 的标签页，**全部常驻挂载、只切显隐**（表单草稿与展开态不丢），视口不再被遮挡。
- **样式单一出处**：`theme.ts` 的 `APP_CSS`（颜色 / 间距 / 控件高度 / 面板与标签页样式）——
  组件里不再堆临时内联色值；旧 `floating-styles.ts` 与 App 内联 CSS 已并入。
- **面板容器** = `Pane`（`ui/Pane.tsx`）：原 `FloatingTile` 的替身（不折叠 / 不定位 / 不量测），
  保留 `summary` / `accessory` 两个参数给既有面板当「一行状态读数 / 顶部常显附件」。
- **不持状态**：Editor 在 `edit/`、store 在 `state/`、组合根在 `app/`；本层经 `getEditor()` /
  `getAiSession()` 服务定位（全图唯一上行边 `ui → app`）。
- **具名命令**：每个按钮 = `commands.ts` 里一个命令对象（名 / 入口 / 可用性），快捷键与 AI 工具表同源。
